# Exercises on Arrays, class and Object, Wrapper Classes ...

## Project description 

This project contains a couple of exercises linking All fundamentals of java: OOP, wrapper Classes 
and arrays and how to manipulate objects.
A small description of each file:
* **BankAccount.java**
Implements the third bank account exercise, including deposits, withdrawals, and balance management.

* **CourseNumbersArray.java**
  Contains the completed course numbers array exercise, focusing on array manipulation and iteration.

* **DogShelter.java**
  Implements the first two dog shelter exercises, including object creation and shelter management.

* **ManageStudent.java**
  Contains the completed student management exercise, including adding, removing, and displaying students.

* **Student.java**
  Defines the `Student` class used in `ManageStudent.java`, including its attributes, constructors, and methods.
